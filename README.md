# Three-Body Chaos

A pocket three-body simulator. Place three stars, press run, and let gravity decide: every run ends in a collision or an escape.

**Try it:** https://three-body-chaos.vercel.app

## Run it locally

```bash
npm install
npm run dev
```

The physics engine lives in `src/physics/`. `debug.html` is a developer harness that can also replay published periodic orbits (the figure-eight, Broucke A2 and A11).
